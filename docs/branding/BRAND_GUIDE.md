# SummonerKit brand guide

SummonerKit is the product name and **SK** is its compact written mark. The
rights-holder and creator credit is **Mohamed Magdy**.

## Mark

The primary mark is the gold-trimmed chest with the rose-red upward chevron and
cyan status light. The high-resolution source is
[`summonerkit-icon-source.png`](summonerkit-icon-source.png). Desktop, tray,
installer, League-tab, and mobile assets are generated from that source with:

```powershell
npm run assets:icons
```

Small web surfaces use the matching inline vector mark from
`@summonerkit/contracts` so they do not need filesystem access.

## Usage

- Write **SummonerKit** in titles, menus, release files, and user instructions.
- Use **SK** only where space is limited, such as a compact status badge.
- Keep the creator line as “by Mohamed Magdy” when there is room.
- Use the existing charcoal, antique-gold, rose-red, and cyan accent palette.
- Do not combine the mark with Riot Games or third-party logos.
- Rose and Deceive remain names of separately installed integrations; they are
  not alternate names for SummonerKit.

Original SummonerKit artwork and branding are covered by the project license.
Third-party names, logos, assets, and trademarks retain their own rights.
